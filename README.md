# LLM-agent mini-projects

Four small experiments on one shared LLM agent, a set of four small studies.
Each studies the same agent from a different angle. Models: Claude Haiku 5.5, Sonnet 5.5; judge: Opus 5.5.

- Project 1: indirect prompt injection + defenses   -> RESULTS_p1_injection.md
- Project 2: monitoring tool calls, leak + anomaly   -> RESULTS_p2_monitor.md
- Project 3: hallucination + self-verification       -> RESULTS_p3_hallucination.md
- Project 4: API hallucination in generated code     -> RESULTS_p4_code.md

Code: common/ (shared agent), p1_injection/, p2_monitor/, p3_hallucination/, p4_code/
Raw outputs: each project's results/ folder.
Total Claude API cost to produce all results: about $10.00.

Built with an AI coding agent under direction; experiment design and result analysis reviewed by Axror.
